# ZESIA for Codex

Add the ZESIA marketplace in a local Codex client.

```sh
codex plugin marketplace add Rowtion/zesia-agent-plugin --ref codex-marketplace
```

In the ChatGPT desktop app, open the Plugins Directory, select **ZESIA for Codex**, and install **ZESIA Consult**. Restart the app if the source has just been added and is not yet visible.

Use the [shared Setup instructions](./plugins/zesia-consult/README.md) after installation. This catalog contains the exact [Agent Plugin 0.4.14](https://github.com/Rowtion/zesia-agent-plugin/tree/v0.4.14).
