# ZESIA for GitHub Copilot

Register ZESIA's marketplace and install the shared plugin in Copilot CLI.

```sh
copilot plugin marketplace add Rowtion/zesia-agent-plugin#copilot-marketplace
copilot plugin install zesia-consult@zesia-copilot
```

Use the [shared Setup instructions](./plugins/zesia-consult/README.md) after installation. This catalog contains the exact [Agent Plugin 0.4.14](https://github.com/Rowtion/zesia-agent-plugin/tree/v0.4.14).
